# UI Kit — Shop

Главная страница магазина. Источник: `Mr Thank You.fig`, экран `Main Screen`, 1440×4179.

**Файлы**
- `index.html` — готовая страница, открывается напрямую.
- `Home.jsx` — та же структура на `Button` / `Counter` из `components/core/`.

## Секции (в порядке макета)

| # | Секция | Что внутри |
|---|---|---|
| 1 | Nav | фиксированная стеклянная шапка 76px, `backdrop-filter: blur(4px)` |
| 2 | Hero | фото 872px + затемнение, `.s-h1`, подзаголовок, CTA `Shop All To Support` |
| 3 | Best Sellers | фильтр-пилюли, сетка 4 товара, бейджи NEW / SALE / Sold Out, цена `$99` |
| 4 | Our Mission | фото + бирюзовая заливка 70%, три числа со статистикой, CTA |
| 5 | Missions | сетка 4 фонда: Mental Health Services, Save the Children, East Side Riders Bike Club, Brave Trails |
| 6 | Reviews | 4 карточки-отзыва, рамка 1px, радиус 15 |
| 7 | Footer | чёрный `--shop-black`, колонки Help / About / Newsletter, копирайт |

## Правила направления

- Колонка 1312px, поля 64px, gap 24px. Сетка соблюдается везде.
- Рамка 1px `--shop-line`, радиусы 6 / 15 / 40 / 100.
- Тени мягкие: `--shadow-soft-md` и `--shadow-soft-lg`. Жёстких теней тут нет.
- CTA-кнопка розовая `--shop-cta` с чёрной рамкой 1px, высота 44, радиус 40.
- Числа — `font-variant-numeric: tabular-nums`, иначе колонки статистики пляшут.
- Мобильная раскладка: 1000px — сетки схлопываются в 2 колонки, ссылки шапки скрываются.

## Библиотечные токены

Палитра `--lib-*` пришла из стороннего UI-kit вместе с компонент-сетом `Button`. Это **не цвета бренда** — использовать только внутри компонентов магазина (состояния, disabled, серые фоны).
