# UI Kit — Brand Site (Y2K)

Главная страница бренд-направления. Источник: `MrThankYou.fig`, экран `DesktopFull_2`, 1440×5026.

**Файлы**
- `index.html` — готовая страница, открывается напрямую.
- `Home.jsx` — та же структура на React-компонентах из `components/brand/`.

## Секции (в порядке макета)

| # | Секция | Что внутри |
|---|---|---|
| 1 | Header | голубая шапка 90px, чёрная линия 4px снизу, монограмма, `NavPill` ×3, `IconButton` ×4 |
| 2 | Shop Now | кремовый фон, `OutlineHeading` «REP THE VIBE», 4 × `ProductCard` |
| 3 | Marquee | бегущая строка 100px, чёрный на розовом |
| 4 | Mission | 2 колонки: фото + голубая плашка, `BrandButton` «LEARN MORE» |
| 5 | Find a store | голубой + шум, 3 карточки с мятным подвалом и `SectionLabel`, `DotPagination`, `BrandButton` |
| 6 | Who is | фото во всю ширину + затемнение, монограмма 174px, 3 карточки |
| 7 | Where to buy | розовая `Panel`, ghost-заголовок, `RetailerChip` ×6, `BrandButton` |
| 8 | Footer | панель `--sky-400`, колонки SHOP / INFO / SUBSCRIBE, `SubscribeForm`, 3 соц-круга |

## Правила направления

- Обводка **всегда 4px чёрным**. Тоньше — ломает язык.
- Тень **жёсткая, без размытия**: `10px 10px 0`. Цвет тени — голубой на розовом, розовый на кремовом.
- Радиусы только 10 / 30 / 50. Промежуточных нет.
- Интерлиньяж заголовков 100%, наклон италик, обводка текста через `-webkit-text-stroke`.
- Фон страницы `--pink-500`. Секции — острова другого цвета поверх него.
- Шум (`.noise`) только на голубых плоскостях. На розовом не читается.

## Что нельзя

Смешивать с `ui_kits/shop`. Кнопка `.btn` из `components/core` в этой странице выглядит чужой, и наоборот.
