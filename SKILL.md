# Mr. Thank You Design System

Собрана из `MrThankYou.fig` (бренд, Y2K) и `Mr Thank You.fig` (магазин). Полная документация — `readme.md`, браузер системы — `index.html`.

## Как подключить

```html
<link rel="stylesheet" href="design-system/ui/primitives.css">
<link rel="stylesheet" href="design-system/styles.css">
<body data-ds="brand">   <!-- или data-ds="shop" -->
```

`ui/primitives.css` — примитивы (`card`, `badge`, `btn`, `table`, `alert`, `accordion`, `input`).
`styles.css` тянет все токены и CSS компонентов. Отдельные файлы не подключать.
Без `data-ds` роли (`--primary`, `--border`, `--radius`) остаются в нейтральных значениях.

## Первое решение — направление

Система содержит **две несовместимые визуальные системы**. Выбери одну до начала работы:

- **brand** — розовый фон, обводка 4px, жёсткие тени 10,10, радиусы 10/30/50, заголовки с текстовой обводкой. Классы `.t-*`, компоненты `components/brand/`, образец `ui_kits/brand-site/`.
- **shop** — белый фон, рамка 1px, мягкие тени, сетка 1312/64/24. Классы `.s-*`, компоненты `components/core/`, образец `ui_kits/shop/`.

Смешивать нельзя. Кнопка `.b-btn` на странице магазина и `.lib-btn` на бренд-странице — ошибка.

## Правила

1. Цвет только из `tokens/colors.css`. Хардкод hex запрещён.
2. `--lib-*` — палитра стороннего UI-kit, пришедшая с компонент-сетом Button. Не цвета бренда, использовать только внутри компонентов магазина.
3. Размер текста только классом (`.t-title-48`, `.s-body`), не `font-size`.
4. Отступы кратны 4 (`--space-*`). Вне шкалы — только значения из `spacing.css`, они взяты с макета.
5. Радиус только из `radii.css`. Промежуточных значений в макетах нет.
6. Тень только из `shadows.css`. В бренде размытие всегда 0.
7. Логотип — файлом из `assets/logos/`. Не перерисовывать, не воссоздавать по памяти, не менять пропорции.

## Компоненты

13 семейств. `core`: Button (480 вариантов), Counter (20). `brand`: BrandButton, IconButton, NavPill, ProductCard, RetailerChip, SectionLabel, OutlineHeading, Marquee, SubscribeForm, DotPagination, Panel.

У каждого рядом `.jsx`, `.d.ts` и `.prompt.md` с областью применения. Читать `.prompt.md` перед использованием.

## Чего в системе нет

Чекбокс, радио, селект, тултип, таб, модалка, мобильные состояния бренд-направления, бренд-иконки. Понадобится — собирать по правилам выбранного направления и дописывать в `readme.md` → «Intentional additions».
