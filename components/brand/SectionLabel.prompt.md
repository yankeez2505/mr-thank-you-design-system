# SectionLabel

Подпись секции с двойной обводкой 3px + 6px.

**Источник:** MrThankYou.fig, плоская отрисовка в секциях макета

**Когда использовать.** Подпись секции с двойной обводкой 3px + 6px.

**Не использовать,** если направление страницы — чистый магазин. Смешивать бренд-примитивы с UI-kit магазина нельзя.
